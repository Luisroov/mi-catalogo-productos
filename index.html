Cómo publicar esta app en GitHub Pages (Paso a Paso)

Puedes subir este archivo a **GitHub Pages** para tener tu propia página web pública y siempre activa que te permita ver y editar tus datos desde cualquier dispositivo.

  1. Guarda este archivo

    Asegúrate de guardar este archivo fuente como index.html en tu computadora.

  2. Crea un Repositorio en GitHub

    Inicia sesión en GitHub, crea un nuevo repositorio público (ej. mi-catalogo-productos).

  3. Sube el archivo

    Haz clic en "Upload an existing file" y sube el archivo index.html directamente a la rama principal (main).

  4. Activa GitHub Pages

    Ve a Settings > Pages en tu repositorio. En Branch selecciona main y guarda. En 1-2 minutos tu enlace estará listo.

¿Cómo sincronizar con Excel?

Cualquier cambio que realices en la web se guarda automáticamente en el navegador. Cuando desees respaldar o trabajar en tu hoja de cálculo local, usa el botón Exportar a Excel (.xlsx). Para cargar cambios masivos realizados en Excel, usa el botón Importar.
